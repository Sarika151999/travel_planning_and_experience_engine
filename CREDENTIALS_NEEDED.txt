📋 WHERE TO PUT CREDENTIALS

1. GET YOUR CREDENTIALS (follow links below)
2. PUT THEM IN: backend/.env (a text file)
3. HOW I USE THEM: Backend reads this file & connects to Google services

═══════════════════════════════════════════════════════════════

STEP 1: GET THESE CREDENTIALS

A) GOOGLE CLOUD PROJECT ID
   Link: https://console.cloud.google.com/
   Steps: Click dropdown (top-left) → Create project → Copy ID
   Example: "my-project-123456"

B) GEMINI API KEY  
   Link: https://ai.google.dev/
   Steps: Click "Get API Key" → Copy
   Example: "AIzaSyD..."

C) GOOGLE MAPS API KEY
   Link: https://console.cloud.google.com/
   Steps: APIs & Services → Enable Maps API → Credentials → Create Key → Copy
   Example: "AIzaSyD..."

D) CLOUD STORAGE BUCKET NAME
   Link: https://console.cloud.google.com/storage/
   Steps: Create Bucket → Copy name
   Example: "my-travel-bucket"

E) SERVICE ACCOUNT JSON KEY (optional for Cloud Run later)
   Link: https://console.cloud.google.com/iam-admin/serviceaccounts
   Steps: Create account → Create key (JSON) → Download file
   Action: Save to: backend/gcs-key.json

═══════════════════════════════════════════════════════════════

STEP 2: CREATE .env FILE (Where I read the credentials from)

Location: travel_vibe_planning/backend/.env

How to create:
1. Open backend folder
2. Create new file named: .env (NOT .env.txt, just .env)
3. Copy content from: backend/.env.example
4. Replace the YOUR_VALUES with actual credentials you collected

The .env file will look like:
---
GOOGLE_CLOUD_PROJECT_ID=my-project-123456
GOOGLE_API_KEY=AIzaSyD...
GOOGLE_MAPS_API_KEY=AIzaSyD...
GCS_BUCKET_NAME=my-travel-bucket
---

═══════════════════════════════════════════════════════════════

STEP 3: HOW I USE IT

When you run: python -m uvicorn app.main:app --reload

I (the code) will:
1. Read backend/.env file
2. Load the credentials into memory
3. Use them to:
   - Call Gemini API to generate itineraries
   - Call Google Maps for location data
   - Connect to Cloud Storage to save itineraries
4. The app works!

═══════════════════════════════════════════════════════════════

IMPORTANT:
- Never push .env to GitHub (it's in .gitignore - safe!)
- .env file is LOCAL ONLY on your computer
- Each developer/deployment has their own .env
